# Historial original

La publicación de este repositorio usa un historial limpio de un solo commit para no exponer datos personales de versiones anteriores.

El historial de desarrollo previo se conserva solo en copias locales privadas, fuera de este repositorio. No se incluye ningún bundle ni archivo de historial.

Para continuar normalmente desde cualquier equipo, clona este repositorio de GitHub. La rama `main` contiene el código actual. Consulta `NEXUS-NOTES.md` para instalación, pruebas y migración.
